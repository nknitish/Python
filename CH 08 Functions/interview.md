# Interview Questions: Functions

## Core concepts

- Function definition and invocation
- Parameters and return values
- Default, keyword, and variable arguments
- Recursion
- Scope and lifetime of variables

## Frequently asked interview questions with answers

### 1. What is a function in Python?

Answer: A function is a reusable block of code that performs a specific task. It helps reduce repetition and makes code easier to maintain.

### 2. What is the difference between a parameter and an argument?

Answer: A parameter is defined in the function declaration. An argument is the value passed when calling the function.

### 3. What are `*args` and `**kwargs`?

Answer: `*args` accepts multiple positional arguments, while `**kwargs` accepts multiple keyword arguments. They are useful in flexible APIs.

### 4. What is recursion?

Answer: Recursion is when a function calls itself. It is useful for problems such as factorial, Fibonacci, and tree traversal, but it must have a base case.

### 5. What is a lambda function?

Answer: A lambda is an anonymous function written in one line. It is commonly used with higher-order functions such as `map()` and `filter()`.

### 6. What is a variable scope in Python?

Answer: Scope defines where a variable can be used. Local variables exist in a function, while global variables exist at the module level.

- Create a function with default and keyword arguments.
