# Interview Questions: Inheritance and Advanced OOP

## Core concepts

- Base class and derived class
- Single, multiple, and multilevel inheritance
- Method overriding
- `super()`
- Property decorators and getters/setters
- Operator overloading

## Frequently asked interview questions with answers

### 1. What is inheritance?

Answer: Inheritance allows one class to reuse the features and methods of another class. The new class is called a child or derived class.

### 2. What is the difference between a base class and a derived class?

Answer: A base class defines common behavior. A derived class extends or customizes that behavior.

### 3. What is method overriding?

Answer: Method overriding means a child class provides its own implementation of a method defined in the parent class.

### 4. Why is `super()` used?

Answer: `super()` calls the parent class method so the child class can extend or reuse the parent logic instead of rewriting it.

### 5. What is MRO?

Answer: MRO stands for Method Resolution Order. It defines the order Python uses to resolve methods in inheritance chains, especially in multiple inheritance.

### 6. What is polymorphism?

Answer: Polymorphism means different classes can respond to the same method name in different ways. This is a key idea in OOP.

- Create a base class and two derived classes with overridden methods.
- Use `super()` to call the parent constructor or method.
- Explain the MRO with a multiple-inheritance example.
