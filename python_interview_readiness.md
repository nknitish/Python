# Python Interview Readiness Guide

This document is the final checkpoint for becoming interview-ready with Python.

## Core Python concepts you must understand

### 1. Fundamentals

- variables and naming
- data types and type conversion
- operators and precedence
- input and output
- comments and code readability

### 2. Data structures

- list, tuple, set, dict
- indexing, slicing, and iteration
- mutability vs immutability
- dictionary keys/values/items
- set operations like union, difference, intersection

### 3. Logic and flow control

- `if`, `elif`, `else`
- nested conditions
- loops: `for` and `while`
- `break`, `continue`, and `pass`
- list/dict comprehensions

### 4. Functions

- parameters and arguments
- default arguments
- return values
- lambda functions
- `*args`, `**kwargs`
- recursion and base cases
- scope: local, global, nonlocal

### 5. File handling and modules

- file modes (`r`, `w`, `a`)
- `with open()`
- reading/writing text files
- importing modules and packages
- virtual environments and `requirements.txt`

### 6. OOP

- classes and objects
- `__init__()`
- instance vs class variables
- inheritance
- method overriding
- polymorphism
- encapsulation
- property decorators

### 7. Advanced Python

- generators and iterators
- decorators
- closures
- `datetime` and `re`
- `collections` module
- `asyncio`
- type hints

### 8. Real-world skills

- exception handling and custom errors
- debugging
- writing clean reusable code
- writing tests
- parsing JSON and CSV
- using external libraries

## The interview mindset

An interviewer is not looking only for syntax memory. They are checking whether you can:

- reason through code
- explain trade-offs
- spot bugs quickly
- choose the right data structure
- write simple logic under pressure
- communicate clearly

## Quick self-check questions

If you can answer these without notes, you are in good shape:

1. What is the difference between mutable and immutable?
2. Why are strings immutable?
3. What is the difference between list and tuple?
4. What is the difference between `==` and `is`?
5. What is a dictionary and when do you use it?
6. What are `*args` and `**kwargs`?
7. What is a closure?
8. What is inheritance and method overriding?
9. Why is `try/except` needed?
10. What is a generator and why is it useful?
11. What is the `LEGB` rule?
12. How do you create a virtual environment?
13. What is the purpose of `requirements.txt`?
14. How do you debug a program that gives wrong output?
15. What is the difference between a shallow copy and deep copy?

## Final rule

To be interview-ready, practice explaining code aloud, not just writing it. If you can narrate your logic, handle basic debugging, and solve coding problems without panic, you are ready for most Python interviews.
