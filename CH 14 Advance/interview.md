## Frequently asked interview questions with answers

### 1. What is a lambda function?

Answer: A lambda is an anonymous one-line function. It is useful for short operations like sorting or filtering data.

### 2. What is the difference between a list and a generator?

Answer: A list stores all values in memory. A generator yields values one at a time and is more memory efficient for large datasets.

### 3. What is a decorator?

Answer: A decorator wraps a function and modifies or enhances its behavior without changing the original function code directly.

### 4. What is a closure?

Answer: A closure is a nested function that remembers variables from its outer scope even after the outer function has returned.

### 5. What is the LEGB rule?

Answer: LEGB stands for Local, Enclosing, Global, Built-in. Python resolves variable names in that order.

### 6. Why are type hints useful?

Answer: Type hints improve readability and help tools like IDEs and linters detect mistakes earlier, though Python still remains dynamically typed at runtime.
