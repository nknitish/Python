# Interview Questions: Object-Oriented Programming

## Core concepts

- Classes and objects
- Instance attributes and methods
- Constructors
- `self` keyword
- Encapsulation basics

## Frequently asked interview questions with answers

### 1. What is a class?

Answer: A class is a blueprint for creating objects. It defines attributes and methods that describe the behavior of objects.

### 2. What is an object?

Answer: An object is an instance of a class. It holds its own data and can call the methods defined by the class.

### 3. What is `self` in Python?

Answer: `self` refers to the current instance of the class. It is used to access instance attributes and methods inside the class.

### 4. What is `__init__()`?

Answer: It is the constructor method. It runs when an object is created and is used to initialize attributes.

### 5. What is the difference between instance variables and class variables?

Answer: Instance variables belong to a specific object. Class variables are shared across all instances of a class.

### 6. What is encapsulation?

Answer: Encapsulation hides internal details and exposes only necessary methods. It helps protect data and keep code organized.
